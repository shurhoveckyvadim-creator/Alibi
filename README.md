# Алиби

Единственный HTML-исходник: index.html. Стили: styles.css.
Изображение и шрифты находятся в assets; пути относительные.

Распакуйте или скачайте весь проект и откройте index.html. Если браузер блокирует локальные шрифты, используйте HTTP-предпросмотр. Для карты нужен интернет.
GitHub хранит исходники; эта операция не публикует сайт в интернете.

Редакция v16 получена из v15 без изменения дизайна. Исходный v15 сохранён в истории Git. Извлечённые ресурсы побайтно идентичны исходным; обратная сборка проверена.
